# Imágenes del portafolio

Usa una carpeta por proyecto:

```text
public/images/profile/
public/images/projects/campo-claro/
public/images/projects/bulletin-builder/
public/images/projects/waterpoints-monitoring/
public/images/projects/aclimate-redesign/
```

Formatos recomendados: WebP o AVIF, alrededor de 1600 px de ancho. Registra `src`, `alt`, `width`, `height` y, cuando ayude a entender la decisión, `caption`.

La ruta del archivo puede ser la misma en ambos idiomas. El texto alternativo y el pie deben localizarse en `portfolio.es.ts` y `portfolio.en.ts`.
